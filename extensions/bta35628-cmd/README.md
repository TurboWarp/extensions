\# Electra Llama



Electra Llama is a JavaScript extension for ElectraMod.



\## Files



\* `ElectraLlama.js` — Main Electra Llama extension

\* `package.json` — Node.js package information

\* `package-lock.json` — Locked package information

\* `LICENSE` — MIT License



\## Installation



Clone or download this repository, then run:



```bash

npm install

```



\## Check the extension



To check the JavaScript syntax:



```bash

npm run check

```



This runs:



```bash

node --check ElectraLlama.js

```



\## ElectraMod



This extension is designed for use with ElectraMod and can be added to an ElectraMod project as a custom extension.
